# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature on this repository. Include:

- the affected route, component, or dependency
- steps to reproduce the issue
- the potential impact
- any suggested mitigation

Please avoid including real patient data, credentials, access tokens, or other sensitive information in a report.

## Clinical-data warning

OncoCohort is demonstration and research software. It has not been certified for clinical decision-making or approved for storing protected health information. Organizations are responsible for completing their own security, privacy, legal, and regulatory reviews before any production use.
